## ۳. قدم صفر: خرید VPS 🖥️

«ترمیوس» (Termius) خودش سرور نیست؛ فقط یه برنامه‌ست که باهاش به سرورت وصل میشی. سرور رو باید جدا بخری.

**پیشنهاد (چون لوکیشنت اروپاست، راحت می‌تونی بخری):**

- **Hetzner** (پیشنهاد من): سرور CX22، اوبونتو ۲۴.۰۴، ماهی ~۴.۵ یورو — سایت: `hetzner.com`
- جایگزین: OVH، Netcup، یا هر VPS دیگه با حداقل **۱ گیگ رم**

**موقع خرید اینا رو انتخاب کن:**
- سیستم‌عامل: **Ubuntu 24.04** (یا 22.04)
- موقعیت سرور: آلمان (Falkenstein/Nuremberg) خوبه
- بعد از خرید، یه ایمیل میاد با **آدرس IP سرور** + **یوزر (root)** + **پسورد** — اینا رو نگه دار.

---

## ۴. قدم یک: وصل شدن با Termius 📱

1. ترمیوس رو نصب کن (گوشی یا کامپیوتر): `termius.com`
2. بازش کن ← **New Host** (یا + ← New Host)
3. اینا رو پر کن:
   - **Address:** همون IP سرور (مثل `49.12.34.56`)
   - **Username:** `root`
   - **Password:** پسوردی که موقع خرید گرفتی
4. **Save** ← روش بزن تا وصل بشه. اگه پرسید «مطمئنی؟» بگو Yes.
5. الان یه صفحه سیاه می‌بینی با چیزی شبیه `root@server:~#` — یعنی داخل سروری! 🎉

> از این به بعد هر دستوری که می‌گم رو همین‌جا تایپ/پیست کن و Enter بزن.

---

## ۵. قدم دو: ساخت ربات و گرفتن توکن 🤖

1. تو تلگرام برو به **@BotFather**
2. بفرست: `/newbot`
3. یه اسم انتخاب کن (مثل `My Channel Manager`)
4. یه یوزرنیم با آخرِ `bot` انتخاب کن (مثل `mychn_manager_bot`)
5. یه **توکن** میده شبیه `123456:ABC-DEF...` — کپیش کن و نگه دار. 🔑
6. (اختیاری ولی خوب) تو BotFather بفرست `/setprivacy` ← رباتت ← **Disable** (برای دکمه‌ها لازم نیست ولی ضرر نداره).

---

## ۶. قدم سه: گرفتن API_ID و API_HASH 🔐

این برای خوندن کانال‌ها (کتابخونه Telethon) لازمه:

1. برو به `my.telegram.org` (با مرورگر گوشی/کامپیوتر)
2. شماره تلگرامت رو بزن ← کد تایید میاد تو تلگرام ← وارد شو
3. برو به **API Development Tools**
4. یه اپ بساز (اسم و پلتفرم هرچی، مثلاً `mychannel`):
   - **api_id** (یه عدد مثل `123456`) و **api_hash** (یه رشته طولانی) رو نگه دار.

## ۷. قدم چهار: کلید رایگان AI 🆓

حداقل **یکی** کافیه، ولی هرچی بیشتر بهتر (روتر بینشون می‌چرخه):

**۱) Groq (پیشنهاد اول — سریع و رایگان):**
- برو `console.groq.com` ← با گوگل ثبت‌نام کن ← **API Keys** ← **Create API Key** ← کپی کن (با `gsk_...` شروع میشه)

**۲) Gemini (گوگل — رایگان):**
- برو `aistudio.google.com/apikey` ← **Get API Key** ← **Create API Key** ← کپی کن

**۳) OpenRouter (مدل‌های رایگان):**
- برو `openrouter.ai` ← ثبت‌نام ← **Keys** ← **Create Key** ← کپی کن

**۴) Mistral (اروپایی، سریع):**
- برو `console.mistral.ai` ← ثبت‌نام ← **API Keys** ← **New key** ← کپی کن

> کاربرهات بعداً هم می‌تونن با «🎁 اهدای کلید» داخل خود ربات کلید اضافه کنن؛ ربات اول تستش می‌کنه بعد می‌بره تو استخر.

## ۹. قدم شش: نصب و اجرا 🚀

تو ترمینال سرور (داخل پوشه پروژه):

```bash
bash setup.sh
```

این اسکریپت خودش پایتون، محیط مجازی و کتابخونه‌ها رو نصب می‌کنه و یه سرویس می‌سازه که ربات **همیشه روشن** بمونه (حتی بعد از ری‌استارت سرور).

بعدش فایل تنظیمات رو پر کن:

```bash
nano .env
```

این‌ها رو حتماً پر کن (بقیه پیش‌فرض خوب دارن):

```env
BOT_TOKEN=توکنی-که-از-BotFather-گرفتی
API_ID=عددی-که-از-my.telegram.org-گرفتی
API_HASH=رشته‌ای-که-از-my.telegram.org-گرفتی
ADMIN_IDS=آیدی-عددی-خودت
GROQ_KEYS=gsk_xxx
GEMINI_KEYS=AIza_xxx
MISTRAL_KEYS=xxxx
```

- آیدی عددی خودت رو از ربات **@userinfobot** بگیر.
- تو `nano`: با کلیدها بنویس، آخرش `Ctrl+X` بعد `Y` بعد `Enter` برای ذخیره.

حالا روشنش کن:

```bash
sudo systemctl start tcm-bot
sudo journalctl -u tcm-bot -f
```

اگه تو لاگ دیدی `Bot is up` یعنی زنده‌ست! 🎉 (`Ctrl+C` برای خروج از لاگ)

## ۱۰. قدم هفت: راه‌اندازی داخل ربات ⚙️

1. تو تلگرام به رباتت پیام بده: `/start` ← منو میاد.
2. **مهم (فقط ادمین، فقط یه بار):** بفرست `/parser_login` و با شماره/کد/رمز دومرحله‌ای وصل شو — این «پارسر عمومی»ـه که حالت ربات باهاش کانال‌های عمومی رو می‌خونه.
3. **تست سریع:**
   - «🔗 اتصال و کانال‌ها» ← «🎯 کانال مقصد» ← آیدی کانال خودت (مثلاً `@mytestchannel`)
   - خودِ ربات رو تو اون کانال **ادمین** کن (دسترسی ارسال پیام)
   - «📡 کانال‌های مبدا» ← یه کانال عمومی (مثلاً `@BBC` یا هر کانال عمومی)
   - صبر کن؛ پست جدید که تو مبدا بیاد، میاد تو پی‌ویت برای تایید (حالت بررسی پیش‌فرضه) ✅
4. اگه مبدای **خصوصی** می‌خوای: «🔗 اتصال و کانال‌ها» ← «🔗 وصل کردن اکانت شخصی» ← شماره/کد/رمز دومرحله‌ای.

## ۱۱. استفاده روزمره 📌

- **تایید پست‌ها:** تو حالت بررسی، هر پست میاد پی‌ویت با دکمه ✅ تایید / ⏩ ارسال فوری / ❌ رد.
- **انتشار خودکار کامل:** «🕐 تنظیمات انتشار» ← مدل انتشار رو بذار روی ⚡ آنی.
- **قیمت دلار/طلا:** «🌍 محتوای خودکار» ← روشن + ساعت (مثلاً ۹ صبح).
- **اخبار خودکار:** همون‌جا ← روشن + موضوع + تعداد.
- **امضا:** «🎨 استایل و فیلتر محتوا» ← امضای زیر پست.
- **توقف موقت:** «🎛️ کنترل پنل» ← توقف پردازش.
- **آمار:** «📊 محدودیت و آمار» ← مصرف AI امروزت.
- **راهنمای قدم‌به‌قدم:** «❓ بلد نیستم چیکار کنم؟» (۷ مرحله مثل نسخه اصلی).

## ۱۲. اهدای کلید (روتر AI) 🔑

هر کاربر (یا خودت) می‌تونه کلید اضافه کنه:

1. «🔑 کلیدهای AI» ← «🎁 اهدای کلید»
2. ارائه‌دهنده رو انتخاب کن (Groq / Gemini / OpenRouter / DeepSeek / آدرس دلخواه)
3. اگه آدرس دلخواه بود، اول Base URL رو بده (مثل `https://api.xxx.com/v1`)
4. کلید رو بفرست
5. مدل رو بفرست (یا `ok` برای پیش‌فرض)
6. ربات **تستش می‌کنه** — اگه سالم بود میره تو استخر و از همون هم استفاده میشه؛ اگه خراب بود خطاش رو نشون میده.

مدیریت: «🗝️ کلیدهای من» (حذف با `/mykey del <id>`) — ادمین همه رو تو «📊 وضعیت استخر» می‌بینه و با `/delkey <id>` حذف می‌کنه. کلیدهای منقضی/باطل هم خودکار (هر ۶ ساعت) چک و از سرور حذف میشن.

## ۱۳. دستورات پرکاربرد سرور 🖥️

```bash
# دیدن لاگ زنده
```

## ۱۶. سؤالات پرتکرار (FAQ) ❓

**۱. حتماً باید VPS بخرم؟**
برای کار ۲۴ساعته بله. ولی برای «تست» می‌تونی روی کامپیوتر خودت هم اجراش کنی (پایتون ۳.۱۰ یا بالاتر نصب کن، بعد):
```bash
git clone https://github.com/Alisarani7021/telegram-channel-manager.git
cd telegram-channel-manager
pip install -r requirements.txt
cp .env.example .env
python -m bot.main
```
فایل `.env` رو با نوت‌پد باز کن و پرش کن. (روی گوشی با Termux هم میشه ولی فقط برای تست خوبه، پایدار نیست.)

**۲. کلید رایگان AI از کجا بگیرم؟**
قدم چهار همین آموزش: Groq (پیشنهاد اول)، Gemini، OpenRouter. هر سه رایگانن و بدون کارت بانکی.

**۳. سهمیه رایگان Groq تموم نمیشه؟**
نه با مصرف ما. سهمیه رایگانش هزاران درخواست در روزه؛ ربات روزی حداکثر ۶۰ پست پردازش می‌کنه (سقف منصفانه). تازه اگه یه کلید تموم بشه، روتر خودکار میره سراغ کلید بعدی.

**۴. حالت ربات یا شخصی؟ کدوم؟**
اگه مبداهات همه عمومی‌ان (لینک `t.me/xxx` دارن) ← حالت ربات کافیه و هیچ اتصالی لازم نیست. اگه حتی یه مبدای خصوصی/لینک‌دعوتی داری ← اکانت شخصی رو وصل کن.

**۵. اکانت تلگرامم امنه؟ بن نمیشم؟**
سشن اکانت فقط روی سرور خودت ذخیره میشه و هیچ‌جا ارسال نمیشه. رفتار ربات هم مثل یه کاربر عادیه (خوندن کانال + پست با فاصله زمانی). فقط فاصله ارسال رو خیلی کم نکن (کمتر از ۵ دقیقه نذار). هر وقت خواستی از «اتصال و کانال‌ها» خروج بزن تا سشن پاک بشه.

**۶. چرا پست‌های قدیمی کانال مبدا رو نمیاره؟**
عمداً! موقع اضافه کردن مبدا، ربات از همون لحظه به بعد رو دنبال می‌کنه تا کانالت یهو پر از پست قدیمی نشه.

**۷. چند تا کانال می‌تونم داشته باشم؟**
پیش‌فرض: ۵ مبدا و ۲ مقصد برای هر کاربر. از فایل `.env` (`MAX_SOURCES` و `MAX_DESTS`) قابل تغییره.

**۸. می‌تونم بدم دوستام هم استفاده کنن؟**
آره! ربات چندکاربره‌ست. هرکی `/start` بزنه فضای جدا داره (مبدا/مقصد و تنظیمات خودش). فقط یادت باشه سهمیه AI مشترکه، پس هرچی کلید اهدایی بیشتر، بهتر.

**۹. چطور آپدیت کنم؟**
```bash
cd ~/telegram-channel-manager && bash update.sh
```

**۱۰. از کجا بفهمم ربات سالمه و کار می‌کنه؟**
```bash
sudo systemctl status tcm-bot
sudo journalctl -u tcm-bot -f
```
اولی باید بگه `active (running)`. تو تلگرام هم «📊 محدودیت و آمار» مصرف امروزت رو نشون میده.

**۱۱. قیمت دلار/طلا چطور فعال میشه؟**
برای قیمت پایدار یه کلید **رایگان** از `navasan.tech` بگیر (ثبت‌نام ← API Key؛ سهمیه رایگانش روزی ۱۰۰ درخواسته و ما روزی ۱ دونه می‌خوایم!) و بذار تو فایل `.env` جلوی `NAVASAN_KEY`، بعد ربات رو ری‌استارت کن. بدون کلید هم ربات منبع رایگان رو امتحان می‌کنه ولی گاهی قطعه.

**۱۲. هزینه واقعی این سیستم چقدره؟**
فقط همون VPS (حدود ۴ تا ۶ یورو در ماه). همه AIها و ابزارها رایگانن.
